# 현장캠

현장 사진 촬영 + GPS 스탬프 + 지도 뷰어 Android 앱

## 기능
- 📷 카메라 내장 (앱 내에서 바로 촬영)
- 📍 GPS 좌표·고도·시간 자동 스탬프
- 🗺️ OSM 지도 + 사진 핀 표시
- 📁 KML / GeoJSON 레이어 불러오기
- 📤 KMZ / KML / GeoJSON 내보내기 (다운로드 폴더)

## APK 설치
1. Actions 탭 → 최근 빌드 클릭 → Artifacts에서 `현장캠-apk` 다운로드
2. 폰에 전송 후 설치 (설정 → 알 수 없는 앱 허용 필요)

## 권한
- 카메라
- 위치 (GPS)
- 인터넷 (OSM 지도 타일)
